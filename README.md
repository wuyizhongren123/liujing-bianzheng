# 六经辨证用药指导

基于《伤寒论》六经辨证体系的中医用药指导 Web 应用。

## 功能特点

- 十问歌问诊流程
- 六经辨证评分系统
- 方剂推荐（含合方逻辑）
- 药材自动加减
- 完整辨证推理过程
- 管理后台

## 技术栈

- Next.js 16
- React 19
- TypeScript 5
- Tailwind CSS 4
- Supabase PostgreSQL

## 快速开始

### 开发环境

```bash
pnpm install
pnpm dev
```
